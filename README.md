# Indie Wave Magazine

## Курсачик мой милый

**Проектирование и разработка многостраничного сайта музыкального онлайн-журнала**

## Описание проекта

Indie Wave Magazine — многостраничный сайт музыкального онлайн-журнала, выполненный на Vue 3. Пользователь может читать статьи о музыке, фильтровать их по жанрам и десятилетиям, искать по ключевым словам, слушать аудиофрагменты(еще нет) и сохранять понравившиеся материалы в личном кабинете(тоже еще нет).

Дизайн типа гранж.

## Стек
Vue, Vue Router, Pinia 

## Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/sandsandm/Indie-Wave

# Перейти в папку проекта
cd indieWave

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev
